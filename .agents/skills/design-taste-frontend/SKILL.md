# Design Taste Frontend & Redesign Principles

## Objectives
Elevate frontend interfaces beyond generic AI templates to achieve a bespoke, premium, and calm visual finish while preserving existing business logic and brand tokens.

## Redesigning Existing Interfaces
1. **Audit First, Don't Recreate**:
   - Inspect existing components, props, and routes before touching code.
   - Refine margins, paddings, visual balance, and typography sizes.
   - Do NOT rewrite Supabase hooks, auth, or existing routing schemas.

2. **High-End Visual Polish**:
   - Curated contrast ratios (dark theme deep navy/obsidian `#08090b` over harsh pure black).
   - Accents used purposefully (neon green `#22c55e` for active/actions, amber `#f59e0b` for avatars/special badges).
   - Crisp borders (`rgba(255, 255, 255, 0.08)`) and controlled elevation.
   - Smooth 16:9 cinematic media cards with aspect-ratio consistency.
